# canteiro-ui
Design system and interface library for The Canteiro.

Canteiro UI is a design system and interface library created by The Canteiro to structure digital experiences, with particular attention to the presentation of architectural projects.

Its purpose is to provide a reusable technical and spatial foundation without turning different works into identical pages. The library organizes navigation, hierarchy, motion, responsiveness, and accessibility while preserving the identity, rhythm, and narrative of each project.

Rather than imposing a template, Canteiro UI provides open structures: planes, sections, sheets, rails, surfaces, and transitions that can be combined according to the content.

Technology should support the work, not replace its expression.
